零 sgl-kernel 目标架构

用 flag_gems 替换 sgl_kernel / sgl_kernel_npu 后的算子分发架构：sglang-plugin-FL 三层 dispatch 把 sglang 融合算子路由到 flag_gems 的 per-vendor 后端。逐项核实后真正需新写的 只剩 kunlunxin 三类 klx_* kernel，其余为接线（A/B 级）或已有覆盖。

基线 sglang v0.5.10 FlagGems 1878e888f build-infra #599 已并（§3.5 分级） PR #5829 等 review metax 3.8.1.3 · cuda12.8 双路径已实证
封装分发 · 工程化落地形态
统一 runtime + 两个 pip 包，单步安装即可执行服务
这是零 sgl-kernel 方案的最终交付目标：不再为每个后端单独构建 sglang 镜像线， sgl-kernel 编译件从安装清单中消失，kernel 层依赖收敛到 runtime 已内置的 flag_gems。
