## 更新日志

### 2.3.0

*2026-10-31 12:10:39*

移除 `HIP_VISIBLE_DEVICES=all` 这个 ENV。HIP 7.2 只接受设备序号或 GPU UUID，
因此按 NVIDIA 习惯写的 `all` 被解析成空设备列表：`hipGetDeviceCount()` 及由此而来的
`torch.cuda.device_count()` 返回 0，而同一容器内的 `rocm-smi` 却能列出全部 GPU。
该变量不设置即表示全部设备，正是此 ENV 想表达的意思，因此镜像现在默认暴露全部设备，
固定单卡改用 `-e HIP_VISIBLE_DEVICES=<n>`。

*2026-10-27 07:58:45*

- 首次交付：gfx1100（RDNA3，Radeon PRO W7900）的 ROCm 7.2.4，基于 ubuntu:24.04 —— runtime 集合加上编译器栈链接所依赖的 `-dev` 包。
- ROCm 取自 `repo.radeon.com` 而非 filestore tarball，因此镜像采用构建时该仓库提供的各个 point release。一条 pin 把 radeon 的 `rocm-cmake`、`hipcc` 和 `rocminfo` 固定在 Ubuntu universe 也提供的旧构建之上。不安装 DKMS 内核驱动 —— 设备由宿主提供。
- 虽然 torch 和 vLLM 都不链接 `hipsolver-dev`、`hipfft-dev` 和 `miopen-hip-dev`，这三者仍然安装：torch 自己的头文件在 `USE_ROCM` 下会 include 它们的头文件，所以扩展构建 —— 其中包括 flagcx torch wheel —— 缺了它们就会失败。
